## PHASE 1: CRITICAL BUGS

> **App crashes on usage. These must be fixed first.**

### 1.1 — Runtime Crashes

- [ ] `!` **#1** `cli.py:290` — `Severity` referenced but never imported → `NameError` on every `analyze` run. Fix: add `from .models import Severity`
- [ ] `!` **#2** `cli.py:330` — Broken ternary `f"..." if result.damage_assessment else "N/A"` — f-string condition is outside the f-string. Fix: rewrite the conditional properly
- [ ] `!` **#3** `cli.py:309` — `args.quiet` accessed in live mode but `--quiet` only defined on analyze subparser → `AttributeError`. Fix: add `--quiet` to both subparsers
- [ ] `!` **#4** `ingestion.py:102` — Calls `scapy_packet.summary()` which crashes on truncated/malformed packets — no `try/except`. Fix: wrap in try/except
- [ ] `!` **#5** `ingestion.py:103` — Accesses `pkt[TCP].sport` without checking if TCP layer exists → `IndexError` on UDP packets. Fix: guard with `haslayer(TCP)`
- [ ] `!` **#6** `ingestion.py:121` — Calls `pkt[Ether].dst` but some pcaps have no Ethernet layer (raw IP). Fix: guard with `haslayer(Ether)`
- [ ] `!` **#7** `extractor.py:89` — Iterates `reassembled_streams` which is `None` when no streams found → `TypeError`. Fix: add `if streams is None: return []`
- [ ] `!` **#8** `ingestion.py:100` — `flow_bytes += int(pkt_len)` — `pkt_len` can be `None` for malformed packets. Fix: add None check

### 1.2 — Logic Bugs

- [ ] `!` **#9** `models.py:62-66` — `Severity` only has `__ge__` and `__gt__` — `max()`, `sorted()`, and `<=` comparisons fail silently. Fix: add `__le__`, `__lt__`, `__eq__`, `__hash__`
- [ ] `!` **#10** `orchestrator.py` — `_analysis_loop` runs on daemon thread but `time.sleep(60s)` — events between cycles are lost. Fix: reduce interval or add event buffering
- [ ] `!` **#11** `process_monitor.py:180-182` — `proc.cpu_percent()` called twice — second call returns 0% (psutil returns delta between calls). Fix: store first result
- [ ] `!` **#12** `file_monitor.py:120` — File size stored as `stat.st_size` (int) but `stat.st_mtime` is `float` while `FileChange.timestamp` is `datetime` — type mismatch on baseline comparison. Fix: normalize timestamps
- [ ] `!` **#13** `config.py:23-24` — `QUARANTINE_DIR` uses `Path(__file__).resolve().parent.parent` which points to random location depending on install method. Fix: use user home or configurable path
- [ ] `!` **#14** `parser.py` — TLS `ClientHello` parsing assumes specific scapy layer names — breaks on scapy version differences. Fix: test with multiple scapy versions

## PHASE 2: MEMORY & STABILITY

> **App crashes after running for minutes/hours.**

- [ ] `!` **#15** `ingestion.py` — `flow_list` is an unbounded list — PCAP with 1M flows = OOM. Fix: add `max_flows` limit
- [ ] `!` **#16** `ingestion.py` — `seen_src_ips` / `seen_dst_ips` are unbounded sets. Fix: cap at 100K, use HyperLogLog approximation
- [ ] `!` **#17** `behavior_engine.py` — `_events` list grows forever — never trimmed. Fix: add circular buffer or time-based eviction
- [ ] `!` **#18** `alert_system.py` — `_alerts` list grows forever, `_recent_keys` dict grows forever. Fix: add max-size with LRU eviction
- [ ] `!` **#19** `models.py:447` — `ThreatActor.activity_log` unbounded list. Fix: add max 1000 entries
- [ ] `!` **#20** `damage_assessor.py:111` — `_assess_confidentiality` allocates `dict[int, int]` indexed by ALL port numbers — 65K entries. Fix: use defaultdict with counter
- [ ] **#21** `orchestrator.py` — No memory monitoring — live capture can silently consume all RAM. Fix: add periodic memory checks
- [ ] **#22** `process_monitor.py` — `_snapshot_all()` hashes EXE files of every process — hundreds of disk reads per snapshot. Fix: add optional hashing, skip system processes
